# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出しまでを端末内で完結させます。

## プロジェクト概要

Podcast AI Director は、ユーザーが音声ファイルをアップロードするだけで、文字起こし、編集指示の作成、音声編集、完成音声の書き出しまでを行えるポッドキャスト編集ツールです。

複数人が自然に会話するポッドキャストを対象とし、以下の自動化を目指しています。

- 音声の文字起こし（タイムスンプ付き）
- 会話の流れや内容の把握
- 不要部分のカット
- 会話のテンポ調整
- シーン転換・フェード
- BGMの挿入・音量調整
- 編集済み音声の書き出し（MP3 / WAV）

## 開発方針・制約

- 完全無料で利用できる
- ブラウザ上で動作する
- GitHub Pages などの静的ホスティングで公開できる
- サーバーを極力必要としない
- APIキーや有料AIサービスへの依存を避ける
- Windows の一般的な学校用PCでも動作する
- Mac でも利用できる
- できるだけ高い自動化を実現する
- ユーザーに複雑な編集操作を要求しない

## 想定ワークフロー

1. ユーザーが音声ファイルをアップロード
2. ブラウザ内で音声を解析（モノラル・16kHz に変換）
3. AI（Whisper）が音声を文字起こしし、タイムスタンプ付きテキストを生成
4. ユーザーが文字起こし結果を任意のAIに渡し、編集指示を作成
5. 編集指示（JSON）をアプリに貼り付ける
6. アプリが指示を解析し、FFmpeg.wasm で音声を編集
7. 完成した音声をダウンロード

将来的には、文字起こしから編集指示の作成までの工程も自動化する予定です。

## 現在の状態

### 正常に動作すると判断できる機能

- 音声ファイルの読み込み（ドラッグ＆ドロップ対応）
- FFmpeg のロードと再試行機構
- 編集指示 JSON のパースと検証
- タイムライン可視化（CUT / BGM / FADE / MARKER）
- BGM・フェード・カットの FFmpeg フィルタ生成
- 編集後音声の書き出し（MP3 / WAV）

### 修正済みの問題

| 問題 | 対応内容 |
|------|----------|
| AudioContext エラー | メインスレッドで音声をデコードし、Float32Array を Worker に転送 |
| UI フリーズ | 文字起こし処理を Web Worker に移行 |
| 繰り返し hallucination | Whisper 標準の `chunk_length_s:30, stride_length_s:5` を採用 |
| FFmpeg 未ロード | 失敗時にインスタンス破棄、再ロード可能な構造に修正 |

### 未検証・残存リスク

- 長時間音声（30分以上）でのメモリ使用量と安定性
- 実際の複数人会話音声での文字起こし品質
- 長いフィルタグラフでの FFmpeg.wasm 実行成功率
- 学校用PC等低スペック環境での動作確認

## セットアップ・デプロイ

1. 本リポジトリのファイルを GitHub リポジトリに配置
2. GitHub Pages を有効化
3. ブラウザでページを開く（初回はモデルと FFmpeg のダウンロードが必要）
4. 音声ファイルをアップロードして編集を開始

注意：初回アクセス時、Whisper モデルと FFmpeg コアのダウンロードに時間がかかります。キャッシュされるため、2回目以降は短縮されます。

## 注意事項

- 編集指示は JSON として読み込み、許可された操作だけを実行します。任意の JavaScript やコードは実行しません。
- AI の指示を適用する前に、カット位置・BGM位置・音量を必ず確認してください。
- 処理はすべてブラウザ内で行われ、音声ファイルは外部サーバーにアップロードされません。
