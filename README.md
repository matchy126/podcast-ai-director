# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.6.9 変更内容

- **文字起こしスキップ導線の強化（既存編集指示JSONの即時利用）**:
  - STEP 01 に「**文字起こしをスキップして編集指示へ進む →**」ボタンを追加し、すでに編集指示JSONがある場合に文字起こしを飛ばして STEP 03 へ即座に移動できるようにしました。
  - 編集指示JSONを先に読み込んだ（または貼り付けた）状態では、STEP 01 に「編集指示JSONが準備済みのため、文字起こしはスキップできます」のステータスバナーを表示し、音源を選択すると同時に自動で検証・STEP 04（編集実行）へ進めるようにしました。
  - 既存JSONで `version` プロパティが省略されている形式や、操作配列（`[...]`）単体のJSONも自動的に補完して読み込めるように互換性を向上しました。
  - STEP 03 の右上から「文字起こし欄を表示 / 隠す」をいつでも切り替えられるようにしました。
