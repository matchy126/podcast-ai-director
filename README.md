# Podcast AI Director (v0.8.4)

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.8.4 の改善点（進捗％の停止解消・WebGPU強制自動リカバリ）

1. **メインスレッド側の連続進捗アニメーション**
   - CPU（WASM）推論中にワーカースレッドが計算で占有されていても、画面の `%` 表示と解析タイムコードが止まらず滑らかに進み続けるようメインスレッド側で進捗を補間描画します。
2. **15秒スマート分割による高頻度進捗更新**
   - 音声を約15秒単位のブロックへ分割することで、1ブロックあたりの処理時間を短縮し、実完了ベースの `%` 更新頻度を高めました。
3. **WebGPUハング時のワーカースレッド強制再起動＆CPU自動切替**
   - WebGPU推論が20秒間応答しない場合、メインスレッドの監視タイマーがハングしたワーカーを強制終了（`terminate()`）し、デコード済み音声を引き継いでCPU標準モードへ自動切替します。
