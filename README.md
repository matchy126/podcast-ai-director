# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.7.1 変更内容

- **カットによってBGMが途切れ途切れになる問題を修正**:
  - 従来はカット区間ごとにBGMを数十〜百個以上の断片へ分割し、元音源の時刻（カット前の時間）を参照して切り出していたため、トークをカットするたびにBGMも一緒にブツ切りワープし、境界で途切れが発生していました。
  - v0.7.1 では BGM を**編集後のタイムライン上で1本の連続した音声トラック**として生成するように変更しました。これにより、何箇所カットを入れてもBGMのメロディやリズムが途切れず滑らかに流れ続けます。
  - 「場面切り替えSE（`insert` モード）」の挿入区間中だけ連続BGMを一時ミュートするオプション（デフォルトON）を追加し、通常のカットではBGMを連続再生しつつ、シーン切り替えの1秒間だけはSEがクリアに鳴るように両立しました。
