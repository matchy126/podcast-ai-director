# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.7.3 不具合修正・高速化

- **MP4レンダリング終盤（92% / 100%表示）でのフリーズ解消**:
  - サムネイル画像入力（`-loop 1`）に明示的な出力尺（`-t`）を指定し、`filter_complex` 経由での終端デッドロックを解消しました。
  - サムネイル画像を事前にブラウザ側で `1280x720` PNG へ整形してから FFmpeg へ渡すことで、高解像度画像使用時のメモリ負荷を軽減しました。
  - ブラウザ版 WASM 環境で終盤停滞の原因となっていた `-movflags +faststart` 再配置処理を廃止しました。
  - 冒頭／終了 BGM オンリー区間の音量制御から `eval=frame` を廃止し、標準の `asplit` + `atrim` + `afade` 構成に置き換えて高速化しました。
