# Podcast AI Director (v0.8.1)

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.7.1 からの追加機能・改善点

1. **複数BGMプレイリスト＆場面切り替え自動切替**
   - 複数のBGMファイルを順番に並べてプレイリスト化でき、各曲の残り秒数が指定値以下になった後の最初の場面切り替え（SE / MARK）に合わせてクロスフェードしながら次の曲へ自動切替します。
2. **BGMオンリー区間（イントロ / アウトロ）＆自動音量ブースト**
   - トーク開始前（冒頭）とトーク終了後（終了）にBGMだけが流れる秒数を設定でき、その区間中はBGM音量を自動で持ち上げて本編開始・終了時に滑らかに戻します。
3. **MP4動画へのテロップ（字幕）焼き込み**
   - STEP 01 の文字起こし結果、または外部から読み込んだ字幕ファイル（`transcript.json` / `[00:00.0 - 00:05.0]` 形式の TXT / SRT）をカット・SE挿入後のタイムラインに自動同期させ、MP4動画へ焼き込みます（文字サイズ・デザイン・位置を選択可能）。
4. **軽量化＆`FS error` 根本解消（Web Audio API + FFmpeg 単発出力）**
   - カット・複数BGM合成・SE挿入・フェード処理をブラウザ標準の Web Audio API で高速処理し、FFmpeg には完成済み音声1本（と軽量JPEGフレーム）のみを渡すことで仮想メモリ不足エラー（`ErrnoError: FS error`）を解消しました。
