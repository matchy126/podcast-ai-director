# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.7.2 新機能・変更内容

1. **複数曲のBGMプレイリスト＆終盤での場面切り替え連動**:
   - BGMファイルを複数選択・追加・曲順入れ替えできるようになりました。
   - 再生中のBGMの残り時間が終盤（デフォルト：残り20秒以下、設定変更可）に入った状態で次の場面切り替え（SE挿入・話題転換マーカー）に到達すると、前の曲をフェードアウトして次のBGM曲へ自動的に切り替えます。
2. **番組の始まり・終わりのBGMオンリー時間（イントロ／アウトロ）**:
   - 番組の冒頭と終わりに数秒間（デフォルト：各3秒、0〜30秒で調整可）のBGMだけの時間を設けられるようになりました。
   - トークがない冒頭・終了区間だけBGM音量を少し上げ、トークが始まると自然に元のBGM音量へ下げるオートダッキング風カーブ（ON/OFF可）も搭載しています。
3. **MP4動画へのテロップ（字幕）表示 ON/OFF 選択**:
   - STEP 04 に「MP4動画にテロップ（字幕）をつける」チェックボックスを追加しました。
   - STEP 01の文字起こし結果、または後から読み込んだ `transcript.json` / `transcript.txt` / `.srt` のタイムスタンプをカット・SE挿入・イントロ秒数に自動同期し、位置（下・中・上）・文字サイズ・デザイン（黒帯座布団／白文字黒縁／黄文字黒縁）を選んで書き出せます。
