# Podcast AI Director (v0.8.2)

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.8.2 の主な高速化・改善点

1. **WebGPU（GPU推論）の自動有効化**
   - Chrome / Edge などの対応ブラウザでは自動的に WebGPU を使用して推論し、従来の CPU（WASM）推論と比べて数倍〜10倍以上高速化します（非対応環境やエラー時は自動で CPU モードにフォールバック）。
2. **無音区間スキップ（適応型 VAD）**
   - 1.8秒以上の沈黙区間を自動除外し、声が入っている区間だけを詰めて AI に解析させたあと元のタイムスタンプへ自動復元します。
3. **チャンク重複幅（ストライド）の最適化**
   - 重複幅を前後5秒から前後2.5秒へ最適化し、推論ブロック数自体を約20%削減しました。
4. **長尺音源（30分以上）の省メモリ化＆完成予定尺の事前表示**
   - 長尺音声のメモリ消費を抑える自動プロファイル調整と、STEP 04 での完成予定尺表示・複数BGM区間引き継ぎ・任意位置フェードアウトに対応しました。
