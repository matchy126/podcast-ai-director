# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.7.0 変更内容

- **ファイル選択後の「選択されていません」表示バグを修正**:
  - `onchange` イベント内で `input.value = ""` を実行していたため、ファイルを選択した直後にブラウザ標準のファイル選択欄の表示が「選択されていません」へリセットされてしまう問題を修正しました。
  - 選択後はブラウザ標準表示とカスタムステータス表示の双方で選択済みファイル名が維持され、再選択時のみクリック直前にリセットされるように改善しました。
  - STEP 04 の SE ファイル選択欄で親 `<label>` 内にファイル入力とチェックボックスが混在していた HTML 構造を分離し、意図しないイベント干渉を解消しました。
  - STEP 03 の JSON ファイル選択時にも選択中ファイル名を表示するようにしました。
