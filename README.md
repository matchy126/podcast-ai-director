# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.6.6 変更内容

- **文字起こし進捗バーの停止解消・リアルタイム平滑化**:
  - 従来はモデル準備直後に50%まで跳ね上がり、最初の30秒ブロックの推論が完了するまで数十秒間50%で停止して見えていた問題を解消しました。
  - 初回ロード時（モデル取得・WASM初期化: 5〜25% / 文字起こし解析: 25〜96%）と、2回目以降（文字起こし解析: 8〜96%）で進捗レンジを最適化しました。
  - ブロック単位の推論中も実測処理ペースに基づいて `0.1%` 刻みで滑らかに進捗を更新し、解析済み時間と推定残り時間をリアルタイム表示します。
