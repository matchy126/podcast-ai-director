# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.6.5 変更内容

- **場面切り替えSE（効果音・ジングル）指定機能**:
  - STEP 04 に「場面切り替えSEファイル（任意）」の選択欄を追加。
  - JSONの `{"type": "se", "time": 120, "volume": 0.8, "label": "場面転換"}` 操作に対応（タイムラインに `SE` トラックを表示）。
  - さらに「『MARK（話題転換）』位置にもSEを自動挿入」チェックボックスを標準ONで搭載し、既存の `marker` 指示のみを含むJSONでもSEファイルを選ぶだけで場面切り替え音を自動挿入可能にしました。
- **MP4出力 & サムネイル画像指定機能**:
  - 出力形式に `MP4（サムネイル画像付き動画）` を追加し、PNG / JPEG / WebP 等のサムネイル画像を指定してMP4動画として書き出せるようにしました（未選択時はダークネイビーの単色背景で生成）。
  - 静止画動画向けに 1fps + `libx264` (`-tune stillimage -preset ultrafast`) と偶数解像度自動スケーリングを採用し、ブラウザ内でも高速・省メモリでMP4をエンコードします。
  - プレビュー欄（B・編集後）でMP4動画の直接再生に対応しました。
