# Podcast AI Director

ブラウザ上で動作するポッドキャスト編集Webアプリ。AIを活用して音声の文字起こしから編集・書き出し・MP4動画化までを端末内で完結させます。

## v0.6.7 変更内容

- **SE リップル挿入（`mode: "insert"`）対応**:
  - 場面切り替えSEを既存音声・BGMの上に重ねるのではなく、シーン境界にSEの尺（`duration` 秒）だけ無音・黒画面区間を割り込み挿入して後ろの音声を押し出す方式に対応しました。
  - 挿入区間中は元音声もBGMも無音になり、SEだけがクリアに再生されます。
- **既存編集JSON読み込み時の文字起こしスキップ**:
  - 音源読み込み直後から STEP 03（編集指示JSONの読み込み）を利用でき、既存JSONがある場合は文字起こしをスキップして直接レンダリングへ進めます。
